# Rebel Federation

Welcome to the Rebel Federation organization.

We build and maintain open source projects that are useful, understandable, and welcoming to contributors.

## Get involved

- Browse our public repositories to find a project that interests you.
- Read each repository's contributing guide before opening a change.
- Use GitHub Issues for focused bug reports and feature proposals.
- Start a discussion when you are unsure where an idea belongs.

Thanks for helping make our projects better.
