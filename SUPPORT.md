# Support

## Where to ask for help

- Check the repository README and documentation first.
- Search existing issues and discussions before opening a new question.
- Use GitHub Discussions for questions, ideas, and usage help when available.
- Use GitHub Issues for reproducible bugs and actionable feature requests.

Please include the repository, version or commit, environment details, expected behavior, actual behavior, and a minimal reproduction when relevant.

Security issues must be reported privately as described in `SECURITY.md`.
