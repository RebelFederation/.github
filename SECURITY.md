# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Join the [Rebel Federation Discord](https://discord.gg/E9KsgYZ) and get in touch with Team Atlas.

Include:

- The affected repository, version, or commit.
- Clear reproduction steps or a proof of concept.
- The potential impact.
- Any suggested mitigation.

We will acknowledge reports as soon as practical, investigate them, and coordinate disclosure with the reporter.

## Supported versions

Each repository documents its supported versions and security update policy in its own README or release notes.
